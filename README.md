# Single-Page HTML CV

A simple, structured single-page Curriculum Vitae (CV) built using only semantic HTML, complete with essential SEO meta tags, Open Graph (OG) tags, and a favicon link. 

This project follows the requirements of the **[Single-Page CV Project](https://roadmap.sh/projects/single-page-cv)** on roadmap.sh.

## 🚀 Features

- **Semantic HTML Structure**: Organizes content cleanly using semantic tags (`<header>`, `<h1>`, `<h3>`, `<p>`, `<ul>`, `<div>`).
- **SEO Ready**: Includes meta title, description, keywords, and author tags for optimal search engine visibility.
- **Open Graph Protocol**: Configured with OG tags (`og:title`, `og:description`, `og:image`, `og:url`, `og:type`) for social media preview cards.
- **Iconography & Favicon**: Includes favicon support and standard Font Awesome icons.
